# Konfigurasi Environment dan IDE

IDE yang saya pakai adalah Visual Studio Code di Windows.

## Langkah yang dilakukan

1. Memasang ekstensi Python dari Microsoft di VS Code.
2. Membuka folder proyek `python untuk pemula`.
3. Memilih interpreter dengan Ctrl + Shift + P, lalu `Python: Select Interpreter`, dan memilih `.\venv\Scripts\python.exe`.
4. Memastikan pojok kanan bawah VS Code menampilkan interpreter venv.
5. Menjalankan program dari terminal VS Code setelah venv aktif.

## Catatan

Dengan memilih interpreter venv, VS Code memakai paket yang dipasang di venv proyek ini, bukan Python global. Materi Santrikoding membahas PyCharm, tetapi saya memakai VS Code.
