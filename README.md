## Cara menjalankan di Windows

1. Pasang Python dan Git.
2. Clone repositori ini dan buka foldernya di terminal.
3. Buat dan aktifkan virtual environment: `python -m venv venv` lalu `venv\Scripts\Activate.ps1`
4. Pasang paket: `pip install -r requirements.txt`
5. Jalankan program, contoh: `python variable_numbers.py`
